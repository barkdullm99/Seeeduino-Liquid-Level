# Seeeduino-Liquid-Level

This repository contains code for a Seeeduino-based liquid level control system.

## Overview

- **`Seeeduino Data Acquisition.ipynb`**  
  Provided by Professor Anthony Butterfield (University of Utah). This Jupyter Notebook is used for data acquisition and visualization on the computer side.

- **`step_test.py`** and **`codePID.py`**  
  Adapted from code originally provided by Professor Anthony Butterfield. These files are intended to be run directly on the Seeeduino using CircuitPython.

## Instructions

1. Install **CircuitPython** on your Seeeduino board.  
   Follow the instructions at: https://circuitpython.org

2. Upload the desired `.py` file to the Seeeduino and rename it to:
  code.py

3. Depending on your computer and operating system, slight variations or changes may be necessary (e.g., file paths or serial port names).

## Notes

- This setup is intended for educational and experimental use.
- Some hardware configuration or calibration may be required for proper operation.
